بررسی کلیدواژه ی final

از کلیدواژه final میتونیم برای تعریف کلاس، متد و متغیر استفاده کنیم، در ادامه به استفاده از final در هر سه می پردازیم.

تعریف کلاس final

اگه یک کلاس رو با کلیدواژه final در جاوا تعریف کنیم، نمیتونیم از کلاس ارث بری کنیم؛ در مثال زیر یک کلاس رو با کلیدواژه ی final تعریف کردیم.

توجه

کلاس های abstract و اینترفیس ها رو نمیتونیم با final تعریف کنیم. 

public final class MyFinalClass{

}

تعریف متد final

اگه از کلیدواژه final برای متد در جاوا استفاده کنیم، هنگام ارث بری نمیتونیم متد رو بازنویسی (Override) کنیم؛‌در مثال زیر یک متد رو با کلیدواژه ی final تعریف کردیم.

توجه

متد های ابستراکت رو نمیشه با final تعریف کنیم.

public class MyClass{

    public final void myFinalMethod(){
        
    }

}

تعریف متغیر final

اگه یک متغیر رو با کلیدواژه final در جاوا تعریف کنیم مقدار متغیر ثابت میمونه و نمیتونیم تغییرش بدیم؛ در مثال زیر متغیر ها رو با کلیدواژه final تعریف کردیم.

راهنمایی

معمولا فیلد های ثابت یک کلاس رو با final و static تعریف میکنیم و اسمشونو با حروف بزرگ مینویسیم. 

public class MyClass{

    public static final String MY_STATIC_CONSTANT = "x";

    private final int myFinalField = 0;

    public void myMethod(){

        final double myFinalVariable = 32.131;

    }

}

خلاصه

  • کلیدواژه ی final یک کلاس، متد یا متغیر رو برامون نهایی میکنه.
  • اگه کلاس رو با final تعریف کنیم دیگه نمیتونیم از کلاس ارث بری کنیم.
  • اگه یک متد رو با final تعریف کنیم متد در وراثت قابل بازنویسی نیست.
  • اگه یک متغیر رو با final تعریف کنیم مقدارش ثابت میمونه.
