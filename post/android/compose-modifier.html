بررسی کلاس Modifier

کلاس Modifier بین تمام Composable ها مشترک است، با استفاده از Modifier میتونیم یک Composable رو سفارشی‌سازی کنیم.

توجه

کلاس Modifier بین تمام Composable ها مشترکه، برای راحتی در مثال های این مطلب از Modifier برای Text استفاده می‌کنیم.

کلاس Modifier یک کلاس Builder است و ترتیب صدا زدن توابع Modifier مهم است؛ توابع کلاس Modifier تغییر‌ناپذیر (immutable) هستن، یعنی یک بار که مقداردهی بشن دیگه نمیتونیم مقدار جدیدی بهشون بدیم.

به طور قراردادی بهتره هر Composable که تعریف میکنیم یک پارامتر از نوع Modifier داشته باشه.

@Composable
fun MyComposableFunction(modifier: Modifier = Modifier){
    //do something here
}

توابع پرکاربرد

در این بخش توابع پرکاربرد کلاس Modifier رو بررسی میکنیم؛ در UML زیر هر تابع با ویژگی ها و عملکردش مشخص شده.

Modifier
fillMaxSize(): Modifier عرض و ارتفاع Composable اندازه Parent میشه.
fillMaxWidth(): Modifier عرض Composable اندازه Parent میشه.
fillMaxHeight(): Modifier ارتفاع Composable اندازه Parent میشه.
wrapContentSize(): Modifier عرض و ارتفاع Composable اندازه محتوای Composable میشه
wrapContentWidth(): Modifier عرض Composable اندازه ارتفاع محتوای Composable میشه.
wrapContentHeight(): Modifier ارتفاع Composable اندازه ارتفاع محتوای Composable میشه.
size(dp: Dp): Modifier طول و عرض Composable رو به صورت dp تعریف میکنیم.
padding(all: Dp): Modifier یک فاصله ایجاد میکنه.
background(color: Color): Modifier پس زمینه Composable رو تغییر میده.
clip(shape: Shape): Modifier میتونیم گوشه های Composable رو با صدا زدن, ShapeDefaults, CutCornerShape, RoundedCornerShape, CircleShape برش بدیم.
alpha(alpha: Float): Modifier میزان شفافیت Composable رو تعیین میکنه.
border(width: Dp, color: Color, shape: Shape): Modifier دور تا دور Composable رو ترسیم میکنه؛ width: قطر خط، color: رنگ خط و shape: شکل چهار گوشه خط.
shadow(elevation: Dp, shape: Shape, clip: Boolean, ambientColor: Color, spotColor: Color): Modifier یک سایه برای Composable ایجاد میکنه. elevation: ارتفاع لایه, shape: نوع شکلی که با سایه میخوایم ایجاد بشه، clip: سایه قابل برش باشه یا خیر، و دو پارامتر باقی‌مونده رنگ های سایه است.
offset(x: Dp, y: Dp)): Modifier میتونیم برای Composable یک offset تعریف کنیم.
graphicsLayer(block: () -> Unit): Modifier میتونیم بعضی از ویژگی های گرافیکی از جمله (scaleX, scaleY, rotateX, rotateY, rotateZ, alpha, ... ) رو داخل تابع block تعریف کنیم.
clickable(clickable: Boolean, onClickLabel: String?, onClick: () -> Unit): Modifier میتونیم روی Composable کلیک کنیم؛ برای این تابع پارامتر های دیگه ای وجود داره ولی برای خلاصه کردن همین سه تا پارامتر کافیه.
then(modifier: Modifier): Modifier Modifier فعلی رو با یک Modifier دیگه ترکیب میکنه.

هنگام صدا زدن توابع Modifier یک ترتیب استاندارد براشون وجود داره:

  1. ابتدا باید توابع مربوط به Layout رو صدا بزنیم (size, wrapContentSize, width, height, ...).
  2. سپس باید توابع مربوط به ظاهر Composable رو صدا بزنیم (background, border, shadow, clip ...).
  3. در نهایت باید توابع تعاملی مثل clickable رو صدا بزنیم.

در زیر میخوایم به یک متن به اندازه 8 dp از چهار طرف فاصله بدیم.

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp,
        modifier = modifier.padding(8.dp)
    )
}

توجه

پارامتر fontSize ‌برای استایل‌دهی اختصاصی تابع Text است.

میخوایم یک سایه قرمز هم به لایه متن اضافه کنیم.

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp,
        modifier = modifier.padding(8.dp)
            .shadow(elevation = 4.dp, shape = ShapeDefaults.Small, spotColor = Color.Red)
    )
}

حالا یک بکگراند (background) هم بهش اضافه کنیم.

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp,
        modifier = modifier.padding(8.dp)
            .shadow(elevation = 4.dp, shape = ShapeDefaults.Small, spotColor = Color.Red)
            .background(Color(0xFFF5F5F5))            
    )
}

اگه بعد از تعریف یک ویژگی با Modifier (مثلا بک گراند یا border) تابع padding رو صدا بزنیم بین محتوای Composable و ویژگی تعریف شده فاصله ایجاد میشه.

حالا یک فاصله به اندازه 16 dp بین سایه و بکگراند و محتوای متن ایجاد میکنیم.

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp,
        modifier = modifier.padding(8.dp)
            .shadow(elevation = 4.dp, shape = ShapeDefaults.Small, spotColor = Color.Red)
            .background(Color(0xFFF5F5F5))
            .padding(16.dp) //inner padding
    )
}

حالا میخوایم دور تا دور محتوای متن یک border هم ترسیم کنیم و یک فاصله به اندازه 12 dp هم بین border و محتوای متن ایجاد کنیم.

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp,
        modifier = modifier.padding(8.dp)
            .shadow(elevation = 4.dp, shape = ShapeDefaults.Small, spotColor = Color.Blue)
            .background(Color(0xFFF5F5F5))
            .padding(16.dp)
            .border(width = 2.dp, shape = ShapeDefaults.Small, color = Color.Yellow)
            .padding(12.dp) //inner padding for border
    )
}

حالا چی میشه اگه بتونیم رو متن کلیک هم کنیم؟

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp,
        modifier = modifier.padding(8.dp)
            .shadow(elevation = 4.dp, shape = ShapeDefaults.Small, spotColor = Color.Blue)

            .padding(16.dp)
            .border(width = 2.dp, shape = ShapeDefaults.Small, color = Color.Yellow)

}

شکل نهایی Composable باید مطابق تصویر زیر باشه.

حالا هرچی نوشتیمو بریم اجرا کنیم.

import android.os.Bundle
import android.util.Log
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import androidx.compose.foundation.background
import androidx.compose.foundation.border
import androidx.compose.foundation.clickable
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Scaffold
import androidx.compose.material3.ShapeDefaults
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.shadow
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.tooling.preview.Preview
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import ir.kodedevel.helloworld.ui.theme.HelloWorldTheme

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            HelloWorldTheme {
                Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                    MyText("Hello World", modifier = Modifier.padding(innerPadding))
                }
            }
        }
    }
}

@Composable
fun MyText(content: String, modifier: Modifier = Modifier){
    Text(
        text = content,
        fontSize = 50.sp
        modifier = modifier.padding(8.dp)
            .shadow(elevation = 4.dp, shape = ShapeDefaults.Small, spotColor = Color.Blue)
            .background(Color(0xFFF5F5F5))
            .padding(16.dp)
            .border(width = 2.dp, shape = ShapeDefaults.Small, color = Color.Yellow)
            .padding(12.dp)
            .clickable{
                Log.d("CLICKED", "clicked on $content")
            }
        )
}

@Preview
@Composable
fun MyTextPreview(){
    MyText("Hello World!")
}

در کد بالا از innerPadding مربوط به تابع Scoffold استفاده کردیم، اگه از innerPadding استفاده نکنیم، Composable میوفته روی استاتوس بار در بالای وسیله اندرویدی؛ در واقع innerPadding یک فاصله بین لایه کامپوز اصلی و حاشیه های وسیله ی اندرویدی ایجاد میکنه.

کلاس Log یک کلاس استاتیک اندروید است که باهاش میتونیم لاگ های برنامه رو از طریق LogCat ببینیم داخل اندروید استادیو لاگ‌کت رو باز کنید و با هربار کلیک روی متن نتیجه پیغامی که داخل Log.d نوشتیم رو نمایش میده؛ برای باز کردن تب لاگ‌کت در پایین سمت چپ اندروید استادیو مطابق تصویر روی علامتی که دورش خط قرمز کشیده شده کلیک کنید.

خلاصه

  • کلاس Modifier یک کلاس عمومی بین تمام Composable هاست.
  • به طور کلی بهتره هر Composable که تعریف میکنیم یک کلاس Modifier به عنوان پارامتر براش تعریف کنیم.
  • کلاس Modifier نوعی builder است و ترتیب صدا زدن توابع داخل کلاس مهم است.
  • توابع Modifier تغییر‌ناپذیر هستن
  • اگه بعد از تعریف یک ویژگی برای Composable (مثلا بکگراند) تابع padding رو صدا بزنیم بین محتوای Composable و ویژگی تعریف شده فاصله ایجاد میشه.
