چرا باید از اندروید استادیو استفاده کنیم؟

اندورید استادیو در واقع یک محیط کد نویسی برای نوشتن برنامه های اندرویدیه، میتونیم یک پروژه ی اندرویدی رو بدون استفاده از اندروید استادیو و حتی با استفاده از تکست ادیتور های معمولی و ترمینال ایجاد و اجرا کنیم اما استفاده از اندروید استادیو خیلی از کار ها رو برامون راحت تر میکنه، مثلا باگ های برنامه رو راحت تر پیدا میکنیم و فایل های پروژه رو راحت تر مدیریت میکنیم و در اندروید استادیو علاوه بر کد نویسی میتونیم از ابزار های ویژوالی محیط اندروید استادیو برای توسعه ی پروژه استفاده کنیم.

پس اندروید استادیو برای توسعه ی یک پروژه اندرویدی لازم نیست اما وجودش به کار هامون سرعت میده.

ایجاد پروژه در اندروید استادیو

برای ایجاد پروژه در اندروید استادیو ابتدا اندروید استادیو رو باز میکنیم و سپس روی New Project کادر قرمز در تصویر زیر کلیک میکنیم.

در این مرحله نوع قالبی که میخوایم برای پروژه ایجاد بشه رو انتخاب میکنیم و سپس next رو میزنیم؛ برای شروع Empty Activity رو انتخاب کنید.

در این مرحله در قسمت Name نام پروژه (برنامه) رو می نویسیم.

در قسمت Package name نام پکیج رو مینویسم؛ نام پکیج باید برعکس ادرس دامنه و زیر دامنه یک سایت باشه، به عنوان مثال اگه آدرس سایت appname.company.com باشه در پروژه اندرویدی نام پکیج به صورت com.company.appname در نظر گرفته میشه که com نام دامنه، company نام کمپانی یا شرکت و appname نام برنامه است.

در قسمت Save location مسیر ذخیره ی پروژه رو انتخاب میکنیم و در قسمت Minimum SDK حداقل نسخه ی اندروید رو برای اجرای پروژه انتخاب میکنیم.

در قسمت Build configuration language هم زبان ساخت پروژه توسط گریدل رو میتونیم kotlin یا groovy انتخاب کنیم که به صورت پیشفرض کاتلینه و کاری بهش نداریم.

و در نهایت finish رو میزنیم و پروژه شروع به سینک شدن می‌کنه.

استفاده از مخازن داخلی در پروژه اندرویدی

با توجه به تحریم های گوگل بر روی ایران، برای سینک پروژه و دانلود راحت تر وابستگی (Dependency) های پروژه ی اندرویدی راحت ترین راه استفاده از مخازن داخلی در پروژه برای سینک و دانلود وابستگی (Dependency) های پروژه است؛ بنابراین دو مخزن (Repository)
maven { url = uri("https://maven.myket.ir") }
maven { url = uri("https://maven.devneeds.ir") }
رو به صورت زیر داخل فایل settings.gradle.kts قرار بدید. 

pluginManagement {
    repositories {
        maven { url = uri("https://maven.myket.ir") }
        maven { url = uri("https://maven.devneeds.ir") }
        google {

            content {
                includeGroupByRegex("com\\.android.*")
                includeGroupByRegex("com\\.google.*")
                includeGroupByRegex("androidx.*")
            }
        }
        mavenCentral()
        gradlePluginPortal()
    }
}
plugins {
    id("org.gradle.toolchains.foojay-resolver-convention") version "1.0.0"
}
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        maven { url = uri("https://maven.myket.ir") }
        maven { url = uri("https://maven.devneeds.ir") }
        google()
        mavenCentral()
    }
}

rootProject.name = "Hello World"
include(":app")

بخش های مختلف پروژه اندرویدی

با استفاده از اکسپلور اندروید استادیو میتونیم به گشت و گذار در پروژه اندرویدی بپردازیم؛ مانند تصویر زیر در بخش اکسپلور اندروید استادیو روی Project (کادر قرمز رنگ) کلیک کنید؛ با کلیک بر روی این قسمت فایل ها در اکسپلور اندروید استادیو به صورت پروژه ای نمایش داده میشه.

بعد از انتخاب نحوه نمایش به صورت Project میتونیم قسمت های مختلف پروژه اندرویدی رو ببینیم.

فایل های اصلی پروژه (کد ها و منابع مورد نیاز) داخل app/src قرار دارن.

داخل پوشه src سه پوشه androidTest, main و test وجود داره.

androidTest

زمانی که نیاز به محیط اندرویدی برای تست کد ها داشته باشیم کد های تست junit رو داخل این پوشه می نویسیم.

test

زمانی که بخوایم کد ها رو با JVM تست کنیم، کد های تست junit رو داخل این پوشه می نویسیم.

main

داخل پوشه main دو پوشه res و java به همراه یک فایل به نام AndroidManifest.xml وجود داره.

java

پکیجی که هنگام ایجاد پروژه تعریف کردیم، داخل پوشه java قرار میگیره و به طور عمومی کد های جاوا و کاتلین داخل پکیج تعریف شده قرار میگیرن.

res

منابع مورد نیاز برنامه از جمله گرافیک ها، عکس ها، استرینگ های لوکالیز و... داخل پوشه res قرار میگیرن.

AndroidManifest.xml

میتونیم مجوز ها و کانفیگ های برنامه اندرویدی رو داخل فایل AndroidManifest.xml تعریف کنیم.

خلاصه

  • استفاده از اندروید استادیو کار رو برای توسعه پروژه های اندرویدی راحت تر می کنه.
  • با استفاده از اکسپور اندروید استادیو به گشت و گذار در قسمت های مختلف پروژه می پردازیم.
  • فایل های اصلی پروژه در پوشه src قرار دارن.
  • کد های جاوا یا کاتلین پروژه در پوشه java قرار دارن
  • منابع پروژه داخل پوشه res قرار دارن
  • در فایل AndroidManifest.xml میتونیم برای برنامه اندرویدی بعضی از مجوز ها و کانفیگ ها رو تعریف کنیم.
