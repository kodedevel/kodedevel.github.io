کامپوننت های تعاملی

کاربر با تله‌پاتی نمیتونه با برنامه کامپیوتری تعامل برقرار کنه! در برنامه های کامپیوتری برای تعامل کاربر با برنامه، بسته به فریم‌ورک مورد استفاده در برنامه کامپوننت هایی وجود دارن که یک برنامه نویس میتونه ازشون برای تعامل کاربر با برنامه استفاده کنه، از جمله این کامپوننت ها میشه به Input ها (میکروفون، تکست فیلد، حسگر اثر انگشت و ...)، Touch (لمس) و Button (دکمه) ها اشاره کرد.

سخت افزار ها معمولا واسطه بین کاربر و کامپوننت های تعاملی میشن، مثلا برای کلیک کاربر روی دکمه، سخت افزار تاچ میتونه واسطه کلیک کاربر باشه.

معمولا در برنامه نویسی تمام این کامپوننت ها از طریق لیستنینگ (Listening) یعنی گوش دادن منتظر کاربر میمونن تا کاربر با برنامه تعامل ایجاد کنه.

یکی از پرکاربردترین و مهم ترین کامپوننت های تعاملی Button است، که وظیفه تعامل کلیکی رو بر عهده داره.

استفاده از Button

تابع Button یکی از کامپوننت های تعاملی در جت‌پک کامپوز است.

فرم کلی

@Composable
fun Button(onClick: () -> Unit, modifier: Modifier, enabled: Boolean, shape: Shape, colors: ButtonColors, elevation: ButtonElevation, border: BorderStroke, contentPadding: PaddingValues, content: @Composable (RowScope) -> Unit)

در UML زیر به بررسی هر کدوم از پارامتر های تابع Button می‌پردازیم.

<<Function>>
Button
onClick: () -> Unit از کلیک کاربر روی دکمه باخیر میشه (میشنوه).
modifier: Modifier باهاش میتونیم Button رو سفارشی کنیم.
enabled: Boolean با مقدار True دکمه قابل کلیک میشه و با مقدار False غیر قابل کلیک (مقدار پیشفرض True است).
shape: Shape شکل دکمه رو تعیین میکنه.
colors: ButtonColors رنگ های دکمه رو تعیین میکنه.
elevation: ButtonElevation ارتفاع دکمه رو تعیین می‌کنه.
border: BorderStroke دور تا دور دکمه رو با یک خط تزئین می‌کنه.
contentPadding: PaddingValues بین محتوای داخل دکمه (به عنوان مثال متن دکمه) و کناره های دکمه فاصله ایجاد می‌کنه.
content: () -> Unit محتوای داخل دکمه رو مشخص میکنیم (مثلا متن دکمه) داخل این تابع میتونیم Composable های دیگه از جمله Text رو صدا بزنیم.

توجه

تابع Button یک تابع پیشفرض برای ایجاد Button است، علاوه بر این تابع توابع دیگه ای هستن که اکثر پارامتر های Button باهاشون مشترکه.

در مثال زیر میخوایم با کلیک روی دکمه یک پیغام در کنسول نمایش داده بشه.

@Composable
fun ConsoleMessage(modifier: Modifier = Modifier){
    Button(
        onClick = {
            Log.d("CONSOLE MESSAGE","Clicked!")
        }
    ){
        Text("Click me!")
    }
}

در مثال زیر میخوایم هنگام کلیک روی دکمه یک پیام موقت در صفحه ظاهر بشه.

@Composable
private fun ScreenMessage(modifier: Modifier = Modifier){

    val context = LocalContext.current

    Column(
        modifier = modifier.fillMaxSize(),
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally,
    ) {

        Button(onClick = {
            Toast.makeText(context, "Current message comes from your click on Button" , Toast.LENGTH_SHORT).show()
        }) {
            Text("Show message")
        }

    }
}

برای نمایش پیغام موقت از کلاس Toast استفاده کردیم، این کلاس چیز خاصی نداره و کل کلاس و موارد استفاده از کلاس همون چیزیه که تو مثال اورده شده است، و LocalContext.current کانتکست Composable مورد نظر رو صدا میزنه و همیشه باید داخل یک Comosable صداش کنیم.

در مثال زیر میخوایم رنگ های Button رو تغییر بدیم.

Button(
    colors = ButtonColors(
                containerColor = Color(0xFF212121),
                contentColor = Color(0xFFFAFAFA),
                disabledContainerColor = Color(0xFFEEEEEE)
                disabledContentColor = Color(0xFF212121),
                ),
     onClick = {
        Toast.makeText(
            context,
            "Current message comes from your click on Button",
            Toast.LENGTH_SHORT
        ).show()
    }) {
    Text("ShowMessage")
}

در بالا containerColor رنگ پس زمینه Button است، contentColor رنگ متن Button و disabledContainerColor و disabledContentColor پس زمینه Button و رنگ متن داخل Button در زمان غیر فعال بودنشه.

در مثال زیر میخوایم ارتفاع رو برای Button برای حالت های پیشفرض، فشار دادن توسط کاربر و غیر فعال بودن تعیین کنیم. 

Button(
    colors = ButtonColors(
        containerColor = Color(0xFF212121),
        contentColor = Color(0xFFFAFAFA),
        disabledContentColor = Color(0xFF212121),
        disabledContainerColor = Color(0xFFEEEEEE)
    ),
    elevation = ButtonDefaults.buttonElevation(
        defaultElevation = 10.dp,
        pressedElevation = 2.dp,
        disabledElevation = 0.dp
    ),
    onClick = {
        Toast.makeText(
            context,
            "Current message comes from your click on Button",
            Toast.LENGTH_SHORT
        ).show()
    }) {
    Text("ShowMessage")
}

در مثال زیر میخوایم Button غیر فعال باشه.

Button(
    enabled = false,
    colors = ButtonColors(

    ),
    elevation = ButtonDefaults.buttonElevation(
        defaultElevation = 10.dp,
        pressedElevation = 2.dp,
        disabledElevation = 0.dp

    onClick = {
        Toast.makeText(
            context,
            "Current message comes from your click on Button",

استفاده از OutlinedButton

تابع OutlinedButton از نظر عملکرد شبیه Button است اما در ظاهر تفاوت هایی با Button داره،‌ داخل این دکمه خالی یا شیشه ایه و دور تا دور دکمه با Border یک خط ترسیم شده است.

در مثال قسمت قبل کافیه بجای Button بنویسیم OutlinedButton.

OutlinedButton(
    onClick = {
        Toast.makeText(context, "Current message comes from your click on OutlinedButton" , Toast.LENGTH_SHORT).show()
    }) {
        Text("Show message")
    }

استفاده از IconButton

داخل IconButton بجای متن یک آیکون رو نمایش میده و برای افزودن آیکون از تابع Icon استفاده می‌کنیم.

تابع Icon

استفاده از تابع Icon مشابه استفاده از تابع Image است و میتونیم مقادیری از نوع ImageVector, ImageBitmap یا Painter رو به عنوان عکس به تابع پاس بدیم، علاوه بر این میتونیم از کلاس Icons استفاده کنیم، کلاس Icons دارای مقادیر ثابت استاتیک از نوع VectorImage است که هر کدوم یک آیکون خاصی رو نمایش میده، برای استفاده از Icons باید وابستگی androidx-compose-material:material-icons-core:$version رو به پروژه اضافه کنیم و بجای $version شماره نسخه مورد نظر رو بنویسیم.

فرم کلی:

@Composable
fun Icon(painter: Painter|imageVector: ImageVector|bitmap: ImageBitmap, contentDescription: String, modifier: Modifier)

کافیه در مثال قبل بجای Button از IconButton استفاده کنیم و در content تابع Icon رو صدا بزنیم.

 IconButton(
    onClick = {
        Toast.makeText(context, "Current message comes from your click on IconButton" , Toast.LENGTH_SHORT).show()
    }) {
        Icon(Icons.Default.Info, contentDescription = null)
    }

قابل کلیک کردن Composable ها با Modifier

با صدا زدن تابع clickable در Modifier میتونیم یک Composable رو قابل کلیک کنیم.

فرم کلی:

Modifier.clickable(enabled: Boolean onClick: () -> Unit)

در بالا enabled فعال یا غیر فعال بودن قابلیت کلیک روی Composable رو تعیین میکنه و داخل onClick کد های لازم برای اجرا هنگام کلیک کاربر روی دکمه رو می‌نویسیم.

در مثال قبل میخوایم به‌جای Button یک Text رو قابل کلیک کنیم.

 Text("Show Message", modifier = Modifier.clickable(enabled = true){
            Toast.makeText(context, "Current message comes from your click on Text" , Toast.LENGTH_SHORT).show()
        }

در موارد گفته شده ElevatedButton و TextButton هم وجود داره اما به طور دستی با پارامتر elevation و Modifier این دوتا رو تو مثال ها به صورت دستی پیاده کردیم.

مورد مطالعه (مثال) ها

در برنامه زیر تمام موارد گفته شده رو اجرا می‌کنیم.

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                ScreenMessage(modifier = Modifier.padding(innerPadding))
            }
        }
    }
}

@Composable
private fun ScreenMessage(modifier: Modifier = Modifier) {

    val context = LocalContext.current

    Column(
        modifier = modifier.fillMaxSize(),
        verticalArrangement = Arrangement.Center,
        horizontalAlignment = Alignment.CenterHorizontally,
    ) {

        Button(
            enabled = true,
            colors = ButtonColors(
                containerColor = Color(0xFF212121),
                contentColor = Color(0xFFFAFAFA),
                disabledContentColor = Color(0xFF212121),
                disabledContainerColor = Color(0xFFEEEEEE)
            ),
            elevation = ButtonDefaults.buttonElevation(
                defaultElevation = 10.dp,
                pressedElevation = 2.dp,
                disabledElevation = 0.dp
            ),
            onClick = {
                Toast.makeText(
                    context,
                    "Current message comes from your click on Button",
                    Toast.LENGTH_SHORT
                ).show()
            }) {
            Text("ShowMessage")
        }

        OutlinedButton(
            border = ButtonDefaults.outlinedButtonBorder(
                enabled = true
            ),
            onClick = {
                Toast.makeText(
                    context,
                    "Current message comes from your click on OutlinedButton",
                    Toast.LENGTH_SHORT
                ).show()
            }) {
            Text("Show message")
        }

        IconButton(onClick = {
            Toast.makeText(
                context,
                "Current message comes from your click on IconButton",
                Toast.LENGTH_SHORT
            ).show()
        }) {
            Icon(Icons.Default.Info, contentDescription = null)
        }

        Text(
            "Show Message", modifier = Modifier
                .clickable(enabled = true, onClickLabel = "Click") {
                    Toast.makeText(
                        context,
                        "Current message comes from your click on Text",
                        Toast.LENGTH_SHORT
                    ).show()
                })
    }
}

خلاصه

  • با استفاده از کامپوننت های تعاملی یک فریم‌ورک کاربر میتونه با برنامه تعامل ایجاد کنه.
  • یکی از کامپوننت های پرکاربرد Button است.
  • در جت‌پک کامپوز برای تعریف دکمه سه تابع Button, OutlinedButton و IconButton رو داریم.
  • برای ایجاد دکمه ی معمولی از Button استفاده می‌کنیم.
  • برای نمایش دکمه Outlined از OutlinedButton استفاده می‌کنیم.
  • برای نمایش دکمه آیکون دار از IconButton استفاده می‌کنیم.
  • با استفاده از تابع clickable در Modifier میتونیم Composable ها رو قابل کلیک کنیم.
