بررسی و استفاده از دستور cd در لینوکس

یکی از برنامه های پر کاربرد در ترمینال لینوکس دستور cd است؛ اسم کامل این برنامه change directory (تغییر پوشه) است.

با دستور cd در ترمینال لینوکس قادر خواهیم بود از یک پوشه به پوشه ی دیگه تغییر مسیر بدیم.

توجه

هنگام تعیین مسیر در لینوکس، مسیر ~ برابر با /home/username است.

فرم کلی

cd destination

در مثال زیر میخوایم بریم تو پوشه Videos. 

cd ~/ٰVideos

اگه پوشه ی مقصد داخل پوشه ی فعلی بود نیازی نیست از روت شروع کنیم به تغییر مسیر و به صورت زیر به پوشه ی مقصد میریم

فرض کنید پوشه ی Movies در پوشه ی Videos است.

cd Movies

اگه اسم پوشه فاصله داشت باید اسمشو داخل ' یا " بنویسیم. 

cd Movies/"directory with space"

خلاصه

  • از دستور cd برای تغییر پوشه در ترمینال استفاده می کنیم.
  • نام cd مخفف change directory است.
